# Набори даних

У папці три готові набори. Оберіть **один** — він буде основою вашого проєкту до кінця семестру.

| Файл | Тема | Записів |
|---|---|---|
| `network-devices.json` | мережеве обладнання | 20 |
| `vulnerabilities.json` | відомі вразливості | 20 |
| `sensors.json` | мікроконтролери, датчики та модулі | 20 |

> **Увага.** Дані навчальні та спрощені. Числові характеристики округлені й наведені
> для демонстрації роботи фільтрів і сортування, а не як технічний довідник.
> Не покладайтеся на ці значення в інших дисциплінах.

---

## Спільна структура

Усі три файли влаштовано однаково, тому завдання лабораторних робіт не залежать від обраної теми. Файл містить масив об'єктів; кожен об'єкт — один запис каталогу.

Спільні поля у всіх наборах:

| Поле | Тип | Призначення в проєкті |
|---|---|---|
| `id` | рядок | унікальний ключ; знадобиться для атрибута `key` у React і для посилання на сторінку деталей |
| `name` | рядок | заголовок картки |
| `vendor` | рядок | виробник або джерело; підходить для другого фільтра |
| `category` | рядок | **категорійне поле** — основа випадного списку фільтрації |
| `year` | число | **числове поле** — сортування, фільтр за діапазоном |
| `price` / `cvss` | число | друге числове поле для сортування |
| `tags` | масив рядків | пошук за кількома ознаками; рендеринг вкладеного списку |
| `description` | рядок | текст на сторінці деталей |
| `image` | рядок | шлях до зображення |
| `featured` | булеве | ознака «рекомендоване»; зручна для умовного рендерингу |

## `network-devices.json`

Додаткові поля:

| Поле | Тип | Опис |
|---|---|---|
| `ports` | число | кількість портів |
| `throughput` | число | пропускна здатність, Гбіт/с |
| `poe` | булеве | підтримка живлення через Ethernet |
| `price` | число | орієнтовна ціна, USD |

Значення `category`: `Маршрутизатор`, `Комутатор`, `Точка доступу`, `Міжмережевий екран`.

## `vulnerabilities.json`

Додаткові поля:

| Поле | Тип | Опис |
|---|---|---|
| `product` | рядок | уражений продукт |
| `cvss` | число | базова оцінка CVSS (приблизна) |

| `exploited` | булеве | чи фіксувалося використання в атаках |

Значення `category`: `Віддалене виконання коду`, `Підвищення привілеїв`, `Розкриття інформації`, `Обхід автентифікації`, `Відмова в обслуговуванні`.
Значення `severity`: `Критична`, `Висока`, `Середня`.

## Зображення

Зображення до наборів не додаються — це навмисно. У полі `image` вказано шлях виду
`img/nd-01.jpg`. До блоку 4 у папці `img/` лежить лише `placeholder.svg`, і його достатньо.

Коли дійде до роботи із зображеннями, доберіть власні: збережіть їх у `img/`,
назвіть **латиницею в нижньому регістрі без пробілів** і стисніть до розумного розміру
(до 200 КБ на картку). Формати `.webp` або `.jpg`.

## Власна тема

Ви можете взяти власну предметну область. Вимоги:

- не менше 15 однотипних записів;
- щонайменше 5 полів у кожному записі;
- обов'язково є одне **числове** поле (для сортування) і одне **категорійне** (для фільтрації);
- структура полів однакова в усіх записах — жодного «у цього запису є поле, а в того немає»;
- файл валідний JSON.

Тему потрібно узгодити з викладачем до блоку 4. Перевірити валідність файлу можна на
[jsonlint.com](https://jsonlint.com) або відкривши його у VS Code — редактор підкреслить помилки.

## Робота з файлом

До блоку 6 дані просто переписують у розмітку вручну. З блоку 6 масив підключають як
JS-модуль, а з блоку 8 — завантажують через `fetch`:

```js
const response = await fetch("data/network-devices.json");
const items = await response.json();
```

Зверніть увагу: `fetch` не працює, якщо відкрити сторінку подвійним клацанням
(протокол `file://`). Потрібен Live Server або опублікована версія.
