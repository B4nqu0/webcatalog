## Робочий цикл

Кожна лабораторна робота здається так:

1. внести зміни у файли;
2. на панелі **Source Control** у VS Code написати опис коміту по суті
   (`Додав картку запису`, а не `зміни`);
3. натиснути **Commit**, потім **Sync Changes**;
4. через одну-дві хвилини перевірити опубліковану сторінку;
5. надіслати викладачеві посилання на сайт.
