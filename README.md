# WebCatalog — Каталог Linux-дистрибутивів

Навчальний проєкт із дисципліни «Веб-технології».
Розробляється протягом семестру: від статичної розмітки до застосунку на React.

**Опублікована версія:** https://b4nqu0.github.io/webcatalog/

---

## Тема каталогу

Каталог містить інформацію про популярні Linux-дистрибутиви та їхні основні характеристики. Для кожного дистрибутива зберігається інформація про його сімейство, пакетний менеджер, рік першого випуску, робоче середовище та тип релізу. Каталог може бути корисним студентам, користувачам Linux та людям, які хочуть ознайомитися з особливостями різних дистрибутивів.

**Обраний набір даних:** `data/distributions.json`

---

## Модель даних

Один запис каталогу:

| Поле | Тип | Опис |
|---|---|---|
| `id` | рядок | унікальний ідентифікатор запису |
| `name` | рядок | назва Linux-дистрибутива |
| `family ` | рядок | сімейство або основа дистрибутива |
| `package_manager ` | рядок | пакетний менеджер |
| `release_year ` | число | рік першого випуску дистрибутива |
| `desktop ` | рядок | основне або рекомендоване робоче середовище |
| `stability ` | рядок | тип випуску: Stable або Rolling Release |

## Робочий цикл

Кожна лабораторна робота здається так:

1. внести зміни у файли;
2. на панелі **Source Control** у VS Code написати опис коміту по суті
   (`Додав картку запису`, а не `зміни`);
3. натиснути **Commit**, потім **Sync Changes**;
4. через одну-дві хвилини перевірити опубліковану сторінку;
5. надіслати викладачеві посилання на сайт.
